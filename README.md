# ЗБВ — калькулятор собівартості 2.0

Український адаптивний вебкалькулятор без серверної бази, збірки та бібліотек у застосунку. HTML містить JavaScript, оформлення — у `styles.css`.

## Запуск і вебперегляд

У каталозі репозиторію виконайте `python3 -m http.server 8000 --bind 0.0.0.0` та відкрийте порт 8000 у браузері або доступному вебперегляді середовища. Звичайна локальна адреса: `http://localhost:8000`.

Також можна відкрити `index.html` напряму, але поведінка localStorage для `file://` залежить від браузера. Рекомендований HTTP-запуск зі сталою адресою і портом: інша адреса означає інше локальне сховище. Вебперегляд має дозволяти JavaScript і localStorage.

## Що перевірити

1. **Калькулятор собівартості.** Введіть бетон 1 м³, арматуру 100 кг, електроенергію 20 кВт·год, працю 5 люд.-год. З початковими цінами та ПДВ 20% результат: 11 269,00 грн без ПДВ, 2 253,80 грн ПДВ і 13 522,80 грн разом. Інші обсяги залиште нульовими. Введення автоматично перераховує підсумки; ручна ціна зберігається в довіднику після завершення редагування поля. «Скинути розрахунок» повертає початкові ціни, нульові обсяги й ПДВ 20%, не видаляючи пропозиції та історичні калькуляції.
2. **Матеріали та ресурси.** Є вісім початкових ресурсів: бетон, арматура, закладні деталі, електроенергія, газ, трудові ресурси, ТВО та допоміжні матеріали. Можна додати ресурс зі своєю назвою, категорією та одиницею. ТВО означає тепловологісну обробку; початкова одиниця — година послуги. Всі ціни в гривнях. Ціна з ПДВ використовує загальну редаговану ставку калькулятора.
3. **Комерційні пропозиції.** Додайте дві пропозиції для бетону, вказавши ціну без ПДВ, постачальника, дату та джерело. Натисніть «Затвердити»: калькулятор автоматично використає вибрану ціну. Одночасно вибрано лише одну пропозицію на ресурс. Статус «Затверджена користувачем» не є незалежним підтвердженням ринкової актуальності. Ручне редагування ціни знімає вибір пропозиції.
4. **Історія цін.** Перевірте попередню/нову ціну, джерело та час зміни. Журнал включає затвердження пропозицій, ручні зміни та скидання цін.
5. **Незмінні калькуляції.** Збережіть іменований знімок, змініть затверджену ціну та відкрийте старий знімок: кількості, ціни, ПДВ і підсумки залишаться попередніми.
6. **Налаштування.** Експортуйте JSON, перезавантажте сторінку та відновіть копію. Відновлення перевіряє структуру й арифметику знімків та просить підтвердити заміну даних. Некоректна копія не змінює сховище.

Початкові ціни 4500 грн/м³, 45 грн/кг, 7,20 грн/кВт·год і 425 грн/люд.-год — **навчальні**, без постачальника та комерційної дати. Для інших початкових ресурсів ціна 0 — заповніть її перед реальною калькуляцією. Вигадані ринкові джерела не підключено. Накладні витрати, доставка та прибуток автоматично не додаються.

## CSV-імпорт

У «Комерційних пропозиціях» завантажте шаблон та заповніть його. UTF-8, роздільник `;` або кома, стандартні CSV-лапки; підтримуються десяткові коми. Назви матеріалів мають існувати в довіднику, одиниці мають точно збігатися (без автоматичного перетворення тонн у кілограми). Дата — `РРРР-ММ-ДД`.

```csv
Матеріал;Одиниця;Ціна без ПДВ;Постачальник;Дата;Джерело
```

Перед імпортом видно попередній перегляд; хоча б одна помилка блокує всю операцію. Імпорт створює пропозиції, але не затверджує їх автоматично. CSV обмежений 2 МБ. Прямий XLSX-імпорт у цій версії не реалізовано: збережіть таблицю як CSV у Excel або LibreOffice.

## Зберігання та формули

Дані зберігаються в localStorage цього браузера під ключем `zbv-calculator-v2`. JSON-копія містить довідник, пропозиції, журнал, ставку ПДВ та знімки; незбережені обсяги калькулятора не включені. Очищення даних сайту видаляє локальні дані, тому регулярно експортуйте JSON (відновлення — до 5 МБ). Дані між пристроями не синхронізуються. При пошкодженому сховищі автозапис блокується до відновлення справної копії. Конфлікт запису з іншою вкладкою потребує перезавантаження.

Стаття = кількість × ціна без ПДВ. Собівартість = сума статей. ПДВ = собівартість × ставка / 100. Разом = собівартість + ПДВ. Проміжного округлення немає; відображення — до копійок. Порожні, від’ємні, нечислові та надмірні значення відхиляються.

## Автоматичні перевірки

Node.js 18+:

```sh
node --test calculator.test.js v2.test.js
```

Браузерні перевірки потребують Playwright та Chromium. Щоб встановити їх окремо від застосунку:

```sh
npm install --prefix /tmp/zbv-test-tools playwright@1.62.1
NODE_PATH=/tmp/zbv-test-tools/node_modules /tmp/zbv-test-tools/node_modules/.bin/playwright install chromium
```

Якщо використовується системний Chromium, стандартний шлях — `/usr/bin/chromium`. Інший шлях задайте через `CHROMIUM_PATH` (зокрема шлях до браузера, встановленого Playwright).

```sh
CHROMIUM_PATH="$(NODE_PATH=/tmp/zbv-test-tools/node_modules node -p 'require("playwright").chromium.executablePath()')" \
NODE_PATH=/tmp/zbv-test-tools/node_modules node --test calculator.test.js v2.test.js browser.test.js v2.browser.test.js
```

Тести самі запускають тимчасовий HTTP-сервер. Перевіряються контрольний приклад v1, усі поля та події, формули v2, затвердження цін, CSV, незмінність знімків, JSON, перезавантаження, конфлікт запису та ширини 375/1280 px. Ці перевірки Chromium не є перевіркою інтерфейсу вебперегляду Codex.
