# zbv-calculator
Калькулятор собівартості залізобетонних виробів.

## Запуск

Відкрийте `index.html` у сучасному браузері. Встановлення залежностей і збірка не потрібні.
Або в каталозі репозиторію запустіть `python3 -m http.server 8000` та відкрийте `http://localhost:8000`.

Введіть кількість ресурсів, за потреби змініть ціни без ПДВ та ставку ПДВ.
Результати оновлюються автоматично. Кнопка скидання повертає нульові обсяги та початкові ціни.
Порожні, від’ємні та некоректні значення блокують розрахунок до виправлення.

## Формули

- Кожна стаття = кількість ресурсу × його ціна (арматура — у кг).
- Собівартість без ПДВ = бетон + арматура + електроенергія + праця.
- Сума ПДВ = собівартість без ПДВ × ставка ПДВ / 100.
- Разом з ПДВ = собівартість без ПДВ + сума ПДВ.

Розрахунки виконуються без проміжного округлення; суми відображаються до копійок.
Доставка, прибуток та інші накладні витрати не враховуються.

Перевірка формул: `node --test calculator.test.js` (Node.js 18 або новіший).

JavaScript вбудовано в `index.html`: перерахунок працює навіть у HTML-перегляді без завантаження сусідніх файлів. Обробляються події `input` і `change`.

Браузерний регресійний тест: `node --test browser.test.js` (потрібні доступні пакунок `playwright` та Chromium; шлях можна задати через `CHROMIUM_PATH`). Тест відкриває HTML із заблокованими зовнішніми запитами, перевіряє контрольний приклад, усі поля, валідацію та скидання. Це імітація ізольованого HTML-перегляду, а не перевірка інтерфейсу Codex.
